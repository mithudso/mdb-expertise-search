          Index

          Semantic and hybrid search (optional)

          Keyword search works everywhere. Hybrid and semantic search also need the query embedded with the same model the index was built with, which a local Ollama provides. The query text goes only to that local Ollama.

          Privacy

          • Search, lint and the optimizer run inside the extension and make no network requests.
          • The extension reads a page only when you click it, use its shortcut or its right-click items.
          • The packaged corpus is the redacted, committed corpus of the mdb-expertise-search repository; private local files are never included.

          Shortcuts

          • Alt+Shift+O — optimize the highlighted text (toolbar popup)
          • Address bar: type mdb, a space, then your question
          • Right-click a selection: Optimize selected MQL, Search MongoDB expertise, Lint selected MQL
          • In Search: / focuses the box, ↑/↓ move through results, Enter opens the document
