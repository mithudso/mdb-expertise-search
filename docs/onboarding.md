# Onboarding

1. Read [README](../README.md) and [ARCHITECTURE](ARCHITECTURE.md).
2. Install per [INSTALLATION](INSTALLATION.md); run `mdbx index`, then `mdbx tui` and try the `1`–`9` topics.
3. Read `mdbx/search.py` (ranking) then `mdbx/corpus.py` (chunking); run `pytest -q`.
4. Make a change with a test; follow [CONTRIBUTING](../CONTRIBUTING.md).
