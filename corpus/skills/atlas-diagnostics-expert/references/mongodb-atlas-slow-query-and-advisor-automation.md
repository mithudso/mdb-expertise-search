# Atlas Slow-Query Log and Performance Advisor Automation

## Overview

Atlas exposes Performance Advisor data through Admin API v2 endpoints (suggested indexes, slow query logs, managedSlowMs toggle) and the Atlas CLI, where `atlas api performanceAdvisor <operation>` is autogenerated 1:1 from the API and `atlas performanceAdvisor ...` are hand-written helpers. By default Atlas dynamically adjusts the slow-query threshold from cluster operation times; the managedSlowMs toggle opts out to a fixed 100 ms. Read endpoints need Project Read Only, the toggle needs Project Owner. Both list endpoints take a process (host:port) id and default to the previous 24 hours. Caveat: all evidence found is MongoDB first-party documentation; no independent third-party automation write-ups or critiques were found.

## Core Concepts

### Atlas Slow-Query Log and Performance Advisor Automation (managedSlowMs and Admin API listSuggestedIndexes and Atlas CLI)

- By default Atlas dynamically adjusts the slow-query threshold from the execution time of operations across the cluster. Opting out (disabling managedSlowMs) switches to a fixed 100 ms threshold; MongoDB recommends not setting the fixed threshold lower than 100 ms.[^c1-1][^c1-6]
- Permissions: viewing slow-query collections and suggested indexes needs Project Read Only or higher; enabling/disabling the Atlas-managed threshold needs Project Owner (Organization Owners must add themselves to the project first). Without Project Data Access Read Only or higher, sample-query field values are redacted.[^c1-1][^c1-4]

## Tools & Frameworks

- atlas api performanceAdvisor listSuggestedIndexes` is autogenerated and corresponds 1:1 with the Admin API v2 operation listGroupProcessPerformanceAdvisorSuggestedIndexes. It requires --groupId and --processId (host:port of a mongod/mongos) and accepts --since, --duration (ms), --namespaces, --nIndexes, --nExamples, --itemsPerPage, --pageNum.[^c1-3][^c1-8] _(Atlas Slow-Query Log and Performance Advisor Automation (managedSlowMs and Admin API listSuggestedIndexes and Atlas CLI))_
- atlas api performanceAdvisor listSlowQueryLogs` returns slow-query log lines identified by Performance Advisor and Query Profiler. Optional flags --includeMetrics, --includeOpType, --includeReplicaState add extracted fields; --nLogs caps line count. The pinned API version is 2023-01-01. verified-as-of: 2026-10-14[^c1-4][^c1-8] _(Atlas Slow-Query Log and Performance Advisor Automation (managedSlowMs and Admin API listSuggestedIndexes and Atlas CLI))_
- The CLI toggle is `atlas performanceAdvisor slowOperationThreshold enable|disable` (project-wide); the autogenerated equivalents are `atlas api performanceAdvisor enableManagedSlowMs|disableManagedSlowMs|getManagedSlowMs`, the last reporting current state. (two sources)[^c1-5][^c1-7] _(Atlas Slow-Query Log and Performance Advisor Automation (managedSlowMs and Admin API listSuggestedIndexes and Atlas CLI))_

## Practical Patterns

- Tentative: Index creation through the Performance Advisor UI is one index at a time, and is unavailable if Data Explorer is disabled for the project; for automation, create suggested indexes from mongosh, a driver, or the API instead of the Advisor UI.[^c1-1] _(Atlas Slow-Query Log and Performance Advisor Automation (managedSlowMs and Admin API listSuggestedIndexes and Atlas CLI))_

## Anti-Patterns

- Managed threshold limits: Free (M0) clusters have it disabled by default and cannot enable it; clusters with MongoDB Search enabled do not support it; Performance Advisor is available on M10+ and Flex clusters. verified-as-of: 2026-10-19[^c1-1][^c1-6] _(Atlas Slow-Query Log and Performance Advisor Automation (managedSlowMs and Admin API listSuggestedIndexes and Atlas CLI))_

## Troubleshooting

- If neither --duration nor --since is given, listSuggestedIndexes and listSlowQueryLogs return data from the previous 24 hours; an empty result can simply mean a quiet window or a wrong --namespaces filter.[^c1-3][^c1-4] _(Atlas Slow-Query Log and Performance Advisor Automation (managedSlowMs and Admin API listSuggestedIndexes and Atlas CLI))_
- Performance Advisor ranks suggested indexes by Impact, based on total wasted bytes read, and considers workload on all replica set nodes including secondaries. It cannot suggest indexes for databases using the ctime timestamp format (workaround: iso8601-utc or iso8601-local), and consecutive $match stages may coalesce so the reported query shape differs from the one run. (two sources)[^c1-1][^c1-2] _(Atlas Slow-Query Log and Performance Advisor Automation (managedSlowMs and Admin API listSuggestedIndexes and Atlas CLI))_
- CLI naming varies by release: older/current pages show both listSuggestedIndexes (process-level) and listClusterSuggestedIndexes (cluster-level, takes processIds); Admin API v2 also has a separate Return All Suggested Indexes to Drop operation. Check the pinned CLI version before scripting. (two sources) verified-as-of: 2026-10-19[^c1-7][^c1-8] _(Atlas Slow-Query Log and Performance Advisor Automation (managedSlowMs and Admin API listSuggestedIndexes and Atlas CLI))_
